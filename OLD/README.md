# OLD Directory

This directory contains files that are no longer actively used but are preserved for historical reference. Files are organized into subdirectories based on their original location and purpose.

## Subdirectories

### root_database_backups/
Database backup files that were previously in the project root. These are snapshots from earlier versions (pre-v0.14.0 to v0.17.0) kept for reference.

### root_reports/
Generated reports and output files (coverage reports, Lighthouse audits, debug logs) that were cluttering the project root.

### scripts_documentation/
Historical documentation for scripts, including development resume notes and version histories that are no longer current.

### scripts_data_processing/
One-time Python scripts used to generate seed data (WODs, movements) from PDFs and other sources. The seed data has been finalized, so these scripts are archived.

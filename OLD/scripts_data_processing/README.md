# Data Processing Scripts

One-time Python scripts used to generate and process seed data for movements and WODs.

## Files

| File | Purpose |
|------|---------|
| `generate_high_quality_more_wods.py` | Generate WOD seeds from curated sources |
| `imports_to_seeds.py` | Convert imported data to seed file format |
| `parse_pdfs_to_wods.py` | Extract WOD definitions from PDF documents |
| `extract_wod_names_from_pdfs.py` | Extract WOD names from PDF files |
| `clean_more_wods.py` | Clean and normalize WOD CSV data |
| `filter_candidate_hero_names.py` | Filter and identify Hero workout names |
| `pilot_web_lookup.py` | Web lookup utility for WOD information |

## Why Archived

- These scripts were used to build the initial seed data in `seeds/`
- The seed data (movements, WODs) has been finalized
- Scripts completed their one-time data generation purpose
- No longer needed for regular development

## Reuse

If you need to regenerate or update seed data in the future, these scripts can be referenced or restored. They may need updates for current Python dependencies.

This page was generated by harvesting the repository README, CHANGELOG, and TODO files to surface the application's key features, recent releases, and high-priority work items so they can be turned into marketing and documentation content.

## Project Summary

- Name: ActaLog
- Purpose: Mobile-first fitness tracker for CrossFit / functional fitness athletes to log workouts, track progress, and analyze performance.
- Tech: Go backend, Vue.js frontend (PWA-capable), Docker deployment options.

## Core Features (from README)

- Workout logging (quick-log + detailed workout entries)
- Workout templates and composite templates (reusable WODs and movements)
- Performance tracking and charts (PRs, weight/metric trends)
- Calendar and timeline views for workout history
- Mobile-first responsive design and PWA support for offline recording
- Import/Export and seed data for common movements/WODs
- Multiple DB support (SQLite default, PostgreSQL, MariaDB)
- Docker images and deployment scripts for production
- Three-tier role system: Athlete / Coach / Admin
- Full class scheduling: locations, templates, sessions, reservations, waitlist, credits, documents
- PR Leaderboards and consistency achievements
- Subscription billing with read-only mode enforcement

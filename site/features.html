FEATURES

BUILT FOR ATHLETES.

Everything you need to track, analyze, and improve your CrossFit performance. Mobile-first. Open source. Self-hosted.

CORE FEATURES

AUTOMATIC PR DETECTION

ActaLog automatically detects personal records using the Epley formula for 1RM calculations. Get notified when you crush a new PR for weight, time, or AMRAP workouts.

314 BENCHMARK WODS

Pre-loaded with 314 classic CrossFit benchmark workouts including The Girls, Heroes, and Open workouts. Create custom templates or modify existing ones.

PERFORMANCE ANALYTICS

Visualize your progress with interactive charts. Track movement volume, workout frequency, strength gains over time, and identify trends in your training.

CALENDAR & TIMELINE

Monthly calendar view shows workout dots at a glance. Timeline view provides chronological workout history with full details and PR badges.

QUICK LOG

One-tap workout logging from templates. Designed for gym use with large touch targets. Log your workout in seconds, not minutes.

182 MOVEMENTS

Comprehensive movement library with 182 exercises categorized by type. Track performance across Olympic lifts, gymnastics, cardio, and accessory work.

6 BEAUTIFUL THEMES

MOBILE-FIRST PWA

INSTALL ON ANY DEVICE

Progressive Web App works like a native app. Install directly to your home screen on iOS, Android, or desktop. No app store required.

OFFLINE RECORDING

Record workouts without internet. Data syncs automatically when you're back online. Perfect for gyms with poor connectivity.

INSTANT UPDATES

User-controlled update prompts. No surprise reloads during your workout. Update when you're ready.

ADMIN & GYM FEATURES

MULTI-USER SUPPORT

User registration with email verification. Role-based access control. Admin and user roles with appropriate permissions.

ANNOUNCEMENTS

Admin broadcast system for gym-wide notifications. Keep members informed about schedule changes, events, and achievements.

AUDIT LOGGING

Complete audit trail for data modifications. Track who changed what and when. Essential for gym management compliance.

SUBSCRIPTION BILLING

Built-in subscription management for gym billing. User and organization-level subscriptions. Manual admin control with full audit trail.

BACKUP & RESTORE

Full system backup and restore. Includes database dump, user data, and settings. Restore across different database engines.

ORGANIZATION SUPPORT

Create organizations for gyms or teams. Organization-level subscriptions cover all members. Perfect for box owners.
